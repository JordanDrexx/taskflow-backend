# TaskFlow Backend

Backend del proyecto TaskFlow, desarrollado con Laravel para el curso *Desarrollo Ágil y Frameworks para Aplicaciones Web*.

## Descripción

TaskFlow es una aplicación de gestión de tareas y proyectos. Este repositorio contiene el backend que provee una API RESTful para el frontend.
